So I made a tiny (RP2350) based passkey so that I could enter passwords in a click of a button with full privacy . (So you dont need to type your password in public also you can save upto 4 different password on it )

## Why This

It is a simple and a compile too that can be directly plugged on Laptop to enter a password also no one would see you entering the password so it's even better. 

## Features

- Based on RP-2035A Chip
- Has MCP1700x-330xxTT as Voltage Regulator
- has 4 button to enter 4 different password
- had a boot pin as well to update password
- Plugs directly onto type A female
